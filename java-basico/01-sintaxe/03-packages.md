# Packages
## Conceito
É o endereço da classe dentro da aplicação. Organiza classes relacionadas e evita conflito de nomes.

O Package reflete a estrutura de diretorios. A JVM  exige que o pacote declarado corresponda ao diretório real do arquivo.

## Nomenclatura
O mercado usa o domínio invertido da empresa como prefixo o que garante unicidade global:

````java
br.com.empresa.modulo.submodulo

br.com.empresa.financeiro
br.com.empresa.financeiro.pagamento
br.com.empresa.cadastro

````
